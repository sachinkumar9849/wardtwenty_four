# Icons

This project uses **Bootstrap Icons 1.11** loaded from CDN in every page:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">
```

Usage: `<i class="bi bi-geo-alt"></i>`

Drop any custom SVG icons in this folder and reference them as
`assets/icons/name.svg`.
