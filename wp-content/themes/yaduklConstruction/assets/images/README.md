# Images

- `logo.svg` — primary brand mark (peacock feather + flute + roofline), gold `#C59D5F`.
- `favicon.svg` — favicon version of the mark on a charcoal tile.
- `brand-illustration.jpeg` — the traditional Yadukul line illustration. Used **once**,
  as a subtle low-opacity decorative element in the About section of `index.html`
  and `about.html`. Keep it subtle so the site stays a modern real-estate site.

Property photography is loaded from Unsplash CDN URLs. To go fully offline, download
each photo into this folder and replace the `src` values (all image URLs are grouped
at the top of the build markup and every `<img>` already has descriptive `alt` text).
